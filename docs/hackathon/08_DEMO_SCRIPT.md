# 08 — Demo Script (3 minutes)

## 0:00–0:15 — Problem
"Millions of people receive suspicious messages every day — fake prize SMS, WhatsApp job offers, OTP-harvesting
'verification' messages — but most people never learn what actually makes them dangerous. They find out only after
falling for one."

## 0:15–0:30 — Introduce the product
"ScamShield AI turns any suspicious message into an understandable threat report — with evidence, not accusations."
(Point at landing page: hero + Analyze a Threat CTA.)

## 0:30–1:00 — Run a real analysis
Click **Analyze** → **Upload screenshot** (or pick the Fake Prize demo scenario).
Click run. The cinematic scan overlay: INITIALIZING THREAT SCAN → EXTRACTING SIGNALS → ANALYZING LANGUAGE →
CHECKING LINK INDICATORS → ASSESSING MANIPULATION PATTERNS → GENERATING EXPLANATION.

## 1:00–1:30 — Reveal the report
"Here's the result." Point to:
- Risk Score being animated to its value, with Critical level
- Threat type (Fake Prize) and confidence
- "Why this was flagged" list — numbered, evidence-quoted reasons with contribution ratings
- Signal radar with detected nodes lighting up

## 1:30–2:00 — Attack chain
"Instead of shouting 'scam or safe', ScamShield explains what could happen next." Click **Explore scenario** — each
node illuminates: suspicious message → link clicked → fake login/payment page → credentials/fee provided → account or
funds compromised → downstream impact. State clearly: "This is a defensive simulation — not instructions."

## 2:00–2:20 — Safe reply
Click **Generate safe response / Copy response**. Read the polite reply that shares no sensitive information.

## 2:20–2:40 — Education
Jump to **Learn**: topic cards + the interactive quiz. "Would you trust this message?" → tap Suspicious → explainer.

## 2:40–3:00 — Pitch + closing
Real-world value: ordinary people get context, not panic. Technical execution: heuristics + optional live AI with
strict validation, structured JSON, explainability and safe fallback. Originality: explainable threat intelligence
for ordinary users. Responsible delivery: evidence vs inference vs uncertainty, privacy-first, no harmful
instructions.

**Closing line:**
"ScamShield doesn't replace human judgment. It gives people the context they need to make safer decisions.
Don't just detect the scam. Understand it. Before it understands you."

> Tip: Keep the backend running and use the *Demo scenarios* tab for a zero-dependency live run. Demo Mode is shown
> by design in most judging environments (no API key needed).

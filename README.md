## ✦ What is ScamShield AI?

> **ScamShield AI** turns a suspicious message, screenshot, or link into a full, structured, *explainable* threat report — in seconds.

Most spam filters say *"likely spam"* and stop there. ScamShield goes further: it tells you **what makes the message dangerous**, **which manipulation tactics are being used**, and **what could happen next** — before you fall for it.

<div align="center">

```
┌─────────────────────────────────────────────────────────────────────┐
│                         ScamShield AI Flow                          │
│                                                                     │
│   📱 Suspicious   ──►   🔍 AI Analysis   ──►   📊 Full Report      │
│      Message              (text/image/url)       (score + tactics)  │
│                                                                     │
│   Score 0–100  •  Threat Category  •  Evidence Quotes              │
│   Attack Chain  •  Safe Reply Generator  •  Recommended Actions    │
└─────────────────────────────────────────────────────────────────────┘
```

- Transparent confidence levels & uncertainty disclosures

## 🏗️ Architecture

```
┌──────────────┐   HTTP (Vite proxy)   ┌──────────────────────────────┐
│   React SPA  │ ────────────────────► │        Express API            │
│  (Vite + TS) │ ◄──────────────────── │   /api/analyze                │
└──────────────┘                       │   /api/analyze/image          │
     │   ▲                             │   /api/analyze/url            │
     │   │ JWT Bearer token            │   /api/generate-safe-reply    │
     │   │                             │   /api/history[...]           │
     │                                 │   /api/auth/*                 │
     └─────────────────────────────────┴──────┬──────────────┬─────────┘
                                              │              │
                                   ┌──────────▼───┐   ┌──────▼──────────────┐
                                   │  SQLite DB   │   │  AI Provider        │
                                   │ (node:sqlite)│   │  (optional, any     │
                                   │  summaries   │   │   OpenAI-compatible)│
                                   │  only        │   └──────────────────────┘
                                   └──────────────┘
```

- **Heuristic engine** (`server/src/services/engine.js`) — complete validated reports in demo mode, always active as safety net
- **AI layer** (`server/src/ai/provider.js`) — strict JSON, schema validation, one retry, fallback to engine
- **Storage** — SQLite via built-in `node:sqlite`; stores summaries only, never raw content
- **Auth** — HMAC-signed stateless tokens, scrypt hashing, OTP via Resend/SMTP/console

## 🚀 Quick Start

> **Requirements:** Node.js ≥ 22.5 (uses built-in `node:sqlite`; verified on Node 24)

```bash
# 1. Clone the repo
git clone https://github.com/asifnawaz23/ScamShield-AI.git
cd ScamShield-AI

# 2. Install all dependencies (root + server + client)
npm run setup

# 3. Configure environment
cp .env.example .env
# Edit .env — at minimum set JWT_SECRET
# Leave AI_API_KEY empty to run in DEMO MODE (no AI key needed!)

# 4. Start development servers
npm run dev
# API  → http://localhost:3001
# Web  → http://localhost:5173
```

That's it. Open `http://localhost:5173` and click **Scan message** on the landing page.

## ⚙️ Environment Variables

Copy `.env.example` → `.env` and fill in what you need:

| Variable | Purpose | Default |
|----------|---------|---------|
| `PORT` | API port | `3001` |
| `JWT_SECRET` | Token signing secret — set a long random value | dev default |
| `AI_API_KEY` | Leave empty for demo mode; set to enable live AI | *(empty)* |
| `AI_MODEL` | OpenAI-compatible model name | `gpt-4o-mini` |
| `AI_BASE_URL` | OpenAI-compatible endpoint | `https://api.openai.com/v1` |
| `GOOGLE_CLIENT_ID` | Google OAuth (optional) | *(empty)* |
| `EMAIL_PROVIDER` | `resend` · `smtp` · `console` | auto-detected |
| `RESEND_API_KEY` | Resend API key for email OTP | *(empty)* |

Full variable reference in [`.env.example`](.env.example).

## 🔌 API Overview

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/analyze` | Analyze pasted text |
| `POST` | `/api/analyze/url` | Analyze a URL (structure only, never opened) |
| `POST` | `/api/analyze/image` | Analyze a screenshot (base64 data URI) |
| `POST` | `/api/generate-safe-reply` | Generate a safe reply for the scam message |
| `GET` | `/api/health` | Server health + demo/ai mode |
| `GET` | `/api/demo-scenarios` | Six one-click demo scenarios |
| `GET` | `/api/history` | Analysis history (auth required) |
| `POST` | `/api/auth/signup` | Create account |
| `POST` | `/api/auth/login` | Login with email + password |
| `POST` | `/api/auth/send-otp` | Send 6-digit OTP code |
| `POST` | `/api/auth/verify-otp` | Verify OTP and get token |
| `GET` | `/api/auth/google/url` | Start Google OAuth flow |

## 🔒 Responsible AI & Privacy

- **AI is not a verdict.** Risk scores are probabilistic estimates, never criminal accusations.
- **Evidence → inference → uncertainty** — all outputs distinguish what was observed vs. inferred.
- **Never stores raw messages.** Only summaries and generated reports are persisted.
- **No blind trust in AI.** The rules engine always runs as a safety net; AI output is schema-validated with a fallback.
- **No operational scam help.** The app refuses to provide instructions for committing scams.

## ⚠️ Known Limitations

- Demo-mode image analysis relies on user-supplied visible text (no bundled OCR)
- URL checker inspects structure only — never crawls or queries blocklists
- Dashboard analytics are illustrative demo data, labeled as such
- Rules engine is pattern-based; short or novel messages may score lower
- Hackathon-quality build — not a replacement for your bank's official channels or antivirus
